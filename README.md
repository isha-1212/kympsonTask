# Kypson Mini RFQ Desk

A mini RFQ management application built using Flask, MySQL, HTML and CSS.

## Tech Stack

- Python
- Flask
- MySQL
- HTML
- CSS
- Jinja2

## Features

- View seeded packaging products
- Raise an RFQ
- View existing RFQs
- Submit supplier quotes
- Quotes sorted by lowest unit price
- Cheapest quote marked as Best Price
- MySQL persistence
- Form validation
